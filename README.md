# MAXIMA — канал обновлений кассы

Здесь лежат **только готовые архивы** модуля кассы MAXIMA и два файла-манифеста.
Разработка ведётся в отдельном репозитории; сюда попадает результат.

Репозиторий открытый по одной причине: касса в магазине должна забирать
обновление без пароля. Ключ доступа, вшитый в каждый магазин, сменить нельзя,
не объехав все кассы, — а сам код модуля и так лежит текстом на компьютере
каждого владельца кассы.

## Что где

| Файл | Что это |
|---|---|
| `stable.json` | версия для всех магазинов |
| `beta.json` | версия, которая сначала работает на кассе владельца |
| релизы `v19.0.x.x.x` | сами архивы `kassa_repair-<версия>.zip` |

Манифест канала — это адрес архива, его размер и контрольная сумма SHA-256.
Касса скачивает архив только после того, как сумма сошлась.

## Как касса это использует

Задача Windows «MAXIMA Update Check» раз в час читает манифест своего канала.
Обычный выпуск ждёт нажатия кнопки «התקן עדכון» в настройках кассы; выпуск,
помеченный `required`, касса ставит сама.

Перед заменой файлов делается дамп базы и копия текущей версии. Если после
обновления касса не поднялась — возвращается предыдущая версия.

## Установка кассы

Здесь её нет. Установщик (`.exe`) ставится один раз и выдаётся владельцем.
